Roster Format Guidelines

  • Excel column should have a header such as College ID, PRN, or Student ID.
  • Headers and whitespace are automatically sanitized during processing.
  • Existing approved students for the selected event are retained without duplication.
  • Events marked as "Open to All" ignore this roster and allow any college student to register.
